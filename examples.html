Live examples ​

Each example below is the real output of openink build, made from the spec in the repository's examples/ folder. Click around: buttons, cards, tabs and modals all work.

ExampleShowsSpec
Photo sharing17 screens: feed, stories, reels, explore, messages, profile, a phone-frame mobile view, global modals, and colour on only a few partsspec.yaml
SaaS adminThe color theme: stat cards, area/bar/donut charts, tables, an invite modalspec.yaml
Rental portalTwo languages and two header nav sets (public vs owner)spec.yaml
GalleryEvery block on one screen per familyspec.yaml
Gallery, dark themeThe same gallery built with --theme darkspec.yaml

Run one locally ​

bash
git clone https://github.com/mediuswareltd/openink.git
cd openink
npm install
npx openink dev examples/photo-sharing
